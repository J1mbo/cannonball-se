Known issues:

- No known issues at this time.

Previously listed, now resolved:

- Audio not playing after a restart because SDL's device order changed between boots.
  The output device can now be selected by name (in-game SOUND menu, or
  sound.playback_device_name in config.xml), which survives reordering.

- Some steering-wheel buttons or controls not recognised. All controls can now be bound
  directly from the in-game Configure Inputs editor, which captures whatever you press or
  move, so no external device-mapping database is needed.
